# 🎓 Student Performance Predictor

This project uses Machine Learning (Linear Regression) to predict student marks.

## 📊 Features
- Predicts marks based on study hours, sleep, and previous marks
- Evaluates model using R2 Score & MAE
- Visualizes results using graphs
- Saves model using joblib

## 🛠️ Tech Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Joblib

## 🚀 Run
pip install pandas scikit-learn matplotlib joblib
python project.py

## 💾 Model
Saved as student_model.pkl
